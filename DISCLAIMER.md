# Disclaimer

This project is a bookkeeping and visualization tool for self-directed investors.
It is not financial, investment, tax, accounting, or legal advice.

The app calculates positions, valuation, drift from user-defined target weights,
and rough income/tax estimates from data you provide. It does not decide whether
any security is suitable for you, and it does not replace professional advice.
You are responsible for checking all outputs before using them for trades,
tax filings, reporting, or any other financial decision.

Market prices, FX rates, names, and dividend data are fetched through `yfinance`,
which accesses Yahoo Finance data. This project is not affiliated with Yahoo,
Yahoo Finance, Trade Republic, any broker, or any exchange. If you use this
project commercially or at scale, review the relevant data-provider terms and
use a licensed market-data provider where required.

The bundled files in `data/` are synthetic demo data. Do not commit your real
portfolio, broker exports, secrets, or other sensitive financial records to a
public repository.
